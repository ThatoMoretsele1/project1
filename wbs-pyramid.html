1.1.1 Project Topic and Scope

  • Define problem (production planning inefficiencies)
  • Define objectives (optimisation, decision support)
  • Define system boundaries

1.1.2 Project Proposal

  • Literature review (Operations Research and production planning)
  • Select techniques (Linear Programming and optimisation)
  • Define methodology

1.1.3 Preliminary Project Report

Level 3: Current production workflow analysis

  • Visual workflow representation (process map)

Level 3: Data Preparation

  • Processing times
  • Changeover requirements
  • Plywood specifications

Level 3: Initial Model Development

  • Decision variables
  • Constraints
  • Objective function

1.1.4 Reflection on Learning Video

  • Challenges faced
  • Skills developed
  • Learning insights

1.2.1 Interim Project Report

Level 3: Developed Operations Research Model

  • Decision support system for production planning

Level 3: Model Implementation

  • Software tool (Python, Microsoft Excel, or AnyLogic)

Level 3: Demonstration Results

  • Scenario analysis
  • Planning decision simulations

1.2.2 Oral Presentation

  • Problem overview
  • Model explanation
  • Results and insights
  • Recommendations

1.2.3 Final Project Report

  • Complete Model Documentation
  • Results Analysis

Level 3: Evaluation of Solution

  • Effectiveness of optimisation
  • Practical applicability
  • Limitations

Level 3: Final Recommendations

  • Improvements for plywood production planning
