1.1.1 Project Topic and Scope

  • Define problem (production planning inefficiencies)
  • Define objectives (optimisation, decision support)
  • Define system boundaries

1.1.2 Project Proposal

  • Literature review (Operations Research and production planning)
  • Select techniques (Linear Programming and optimisation)
  • Define methodology

1.1.3 Preliminary Project Report

  • Current production workflow analysis
  • Visual workflow representation (process map)
  • Data preparation: Processing times; Changeover requirements; Plywood specifications
  • Initial model development: Decision variables; Constraints; Objective function

1.1.4 Reflection on Learning Video

  • Challenges faced
  • Skills developed
  • Learning insights

1.2.1 Interim Project Report

  • Developed Operations Research model: Decision support system for production planning
  • Model implementation: Software tool (Python, Microsoft Excel, or AnyLogic)
  • Demonstration results: Scenario analysis; Planning decision simulations

1.2.2 Oral Presentation

  • Problem overview
  • Model explanation
  • Results and insights
  • Recommendations

1.2.3 Final Project Report

  • Complete model documentation
  • Results analysis
  • Evaluation of solution: Effectiveness of optimisation; Practical applicability; Limitations
  • Final recommendations: Improvements for plywood production planning

1.3.1 Techniques

  • Linear Programming
  • Operations Research modelling
  • Process mapping

1.3.2 Software Tools

  • AnyLogic (simulation tools)
  • Microsoft Excel Solver and Python
  • Data analysis tools
